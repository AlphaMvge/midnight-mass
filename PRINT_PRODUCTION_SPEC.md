## 1. Apparel Production Summary

This document specifies the exact technical requirements for manufacturing official **Midnight Mass** merchandise, including print methods, ink types, embroidery specifications, color mappings (HEX to Pantone), resolution, and seam bleed margins.

---

## 2. Product Tech Pack Specifications

### 2.1 Void Cathedral All-Over Heavyweight Hoodie
- **Garment Type**: 450 GSM Oversized Heavyweight Hoodie (100% French Terry Cotton)
- **Garment Color**: Void Black (`#0B0B0B` / Pantone Black 6 C)
- **Print Technique**: All-Over Dye Sublimation or Discharge Water-Based Screen Print (Soft hand feel)
- **Print Placement**: Full seam-to-seam wrap covering Hood, Shoulders, Chest, and Hem
- **Resolution / File Specs**: 300 DPI Vector (SVG / EPS / PDF) with 0.5-inch (12.7mm) seam bleed
- **Monogram Accent**: 15mm × 15mm 3D Puff Micro-Embroidery on Left Wrist Cuff (`MM` Blackletter Monogram)

### 2.2 Blackletter 3D Embroidered Flat Bill Snapback Hat
- **Garment Type**: Structured 6-Panel Flat Bill Snapback Cap
- **Hat Color**: Deep Black Twill (`#0B0B0B`)
- **Embroidery Technique**: 3D High-Density Puff Embroidery with Satin Stitch Outline
- **Placement**: Front Center Panel (Max Width: 110mm, Max Height: 50mm)
- **Stitch Count**: ~14,500 stitches
- **Thread Pantone Mappings**:
  - **Left Section ("The")**: Pantone 1935 C (Rose `#E11D48`)
  - **Center Section ("Midnight")**: Pantone 2665 C (Neon Purple `#8B5CF6`)
  - **Right Section ("Mass")**: Pantone 2728 C (Electric Blue `#2563EB`)
  - **Outline / Inline Stroke**: Pure White Thread (Pantone Bright White)

### 2.3 Abstract Veiled Nun Women's Cropped Tank Top
- **Garment Type**: 180 GSM Ribbed Cropped Tank Top (95% Cotton / 5% Spandex)
- **Garment Color**: Void Black (`#0B0B0B`)
- **Print Technique**: High-Resolution Direct-to-Garment (DTG) with Soft Rubberized White Base
- **Placement**: Centered Front Chest (Max Width: 220mm, Max Height: 280mm)
- **Resolution**: 300 DPI Transparent PNG / Vector PDF

## 4. File Handoff Requirements for Suppliers

1. **Format**: Vector Files (`.SVG`, `.EPS`, `.AI`) or 300 DPI Transparent `.PNG` (Minimum 4000px × 4000px).
2. **Color Profile**: CMYK for screen printing / DTG; Pantone Coated for embroidery.
3. **Fonts**: All text layers converted to outlines / expanded paths.
