**Everything you need to grow, track, and dominate. All in one folder.**

## 🚀 How to Use This Toolkit

### One-Click Launch (Start Here Every Session)
**Double-click** → `LAUNCH.bat`

This single file:
- Starts the local Sacred Codex web server on port 8085
- Opens all 4 tools in your browser automatically
- Starts the 2-hour server bump reminder silently in background
- Optionally generates a fresh QR batch on demand

## ⚡ Daily Workflow

1. **Double-click `LAUNCH.bat`** to open everything
2. Open the **Placement Checklist** and work through HIGH priority spots
3. Use the **QR Generator** to download fresh QR codes for each spot
4. Use the **Email Composer** to draft and log outreach emails
5. At end of day — log today's member count in the **Growth Tracker**
6. The **Bump Reminder** handles everything else automatically every 2 hours
