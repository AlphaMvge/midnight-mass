## 🚀 How to Use This Toolkit

### One-Click Launch (Start Here Every Session)
**Double-click** → `LAUNCH.bat`

This single file:
- Starts the local Sacred Codex web server on port 8085
- Opens all 4 tools in your browser automatically
- Starts the 2-hour server bump reminder silently in background
- Optionally generates a fresh QR batch on demand
