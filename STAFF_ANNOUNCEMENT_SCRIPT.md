   * Export guidelines, resolutions, and dimensions for physical merch or promotional prints.

5. 🖼️ **assets/ Folder & index.html**
   * High-res logos, banners, icons, and an interactive web preview (`index.html`) you can open in any browser to inspect the brand system live.

### 💡 How We Use This:

* **Event & Server Graphics:** Whenever you're creating Discord event graphics, announcement embeds, stream overlays, or social promos, use these exact colors and fonts.

Download, extract, and let's keep the Midnight Mass aesthetic locked in! ⚡
